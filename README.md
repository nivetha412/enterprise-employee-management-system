# Enterprise Employee Management System

Role-based employee management app built with Spring Boot, React and MySQL.

## Features
- JWT authentication and role-based access (Admin, Employee)
- Employee management (add, update, delete, view)
- Department management
- Attendance check-in / check-out

## Tech stack
Java, Spring Boot, Spring Security, React.js, MySQL, JWT

## Run locally
1. Clone: git clone <repo-url>
2. Create a MySQL database named <name>
3. Set your DB username/password in application.properties
4. Backend: mvn spring-boot:run
5. Frontend: npm install, then npm run dev
